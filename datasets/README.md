# 数据集说明（datasets）

按《详细实施方案》2.6 准备鹅养殖知识库与测试集。

## 知识库文件清单（knowledge/）

当前知识库按《详细实施方案》2.6 的**静态知识库来源分类**整理，均为 UTF-8 纯文本（`.txt`），入库命令见 [user_guide](../../docs/user_guide.md) 第 6 节。

| 文件 | 来源类别 | 主要内容 |
|------|----------|----------|
| `鹅养殖疫病基础知识示例.txt` | 专业教材 | 小鹅瘟、鹅副黏病毒病、禽流感、大肠杆菌病、饲养管理要点、综合防控策略 |
| `鸭瘟与鹅副伤寒防控.txt` | 专业教材 | 鸭瘟（大头瘟）、鹅副伤寒的症状识别与防控 |
| `鹅养殖生物安全与疫苗免疫程序.txt` | 技术标准 | 生物安全核心措施、参考免疫程序、分阶段饲养管理 |
| `鹅疫病鉴别诊断与实验室检测要点.txt` | 技术标准 | 常见疫病鉴别要点、病料采集送检、PCR/ELISA/细菌分离等方法 |
| `鹅传染性浆膜炎与寄生虫病防控.txt` | 专业教材 | 传染性浆膜炎、球虫病、绦虫/棘口吸虫/蛔虫/体表寄生虫防控 |
| `鹅营养代谢病与中毒病防控.txt` | 专业教材 | 痛风、维生素与微量元素缺乏、霉菌毒素与食盐中毒等 |
| `鹅常用兽药与用药规范.txt` | 兽药信息 | 用药原则、常用抗菌药与抗寄生虫药、消毒药与疫苗使用要点 |
| `鹅场疫病风险评估与分级管理.txt` | 技术标准 | 风险评估流程、风险因子清单、分级处置、监测与预警 |
| `鹅孵化与育雏期关键控制点.txt` | 专业教材 | 种蛋管理、孵化条件、育雏温湿度/密度/开水开食/免疫 |
| `官方动物防疫要求与病死鹅无害化处理.txt` | 官方数据 | 防疫条件、疫情报告与应急处置、无害化处理方法 |

> 内容为面向系统检索演示整理的知识要点（非原文摘录），具体用药、免疫与处置以官方规范和执业兽医指导为准。
> 学术论文、原始行业标准 PDF、国家兽药基础数据库等外部数据后续按 2.6 清单继续补充。

## 测试集（test_qa/）

- `qa_samples.json`：问答测试集（黄金标准），JSON 数组，每条字段：
  - `question`：问题
  - `expected_answer`：参考答案
  - `source_doc`：来源文档名，需与 `knowledge/` 下文件名**去掉扩展名**一致（`scripts/evaluate_retrieval.py` 据此计算 Hit@K）
- 起步 20–30 条（当前 24 条），最终 50–100 条；补充新知识文档后应同步扩充对应主题的样本。
