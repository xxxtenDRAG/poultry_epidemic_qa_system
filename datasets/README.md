# 数据集说明（datasets）

按《详细实施方案》2.6 准备鹅养殖知识库与测试集。

## 目录

- `knowledge/`：鹅养殖知识库原始文档
  - 起步（阶段 0/1）：采集 **3–5 份 PDF**（鹅病学节选、养殖资料）作为最小测试知识库
  - 后续扩展：学术论文 / 专业教材 / 技术标准 / 官方数据 / 兽药信息
- `test_qa/`：问答测试集（黄金标准）
  - 起步 20–30 条，最终 50–100 条

## 格式建议

- `test_qa/` 下每行一条 JSON：`{"question": "...", "reference_answer": "...", "sources": ["..."], "category": "..."}`
